# Музей Фёдора Павлова

Интерактивная музейная оболочка для сенсорного стола на Python + Flask.

## Возможности
- крупный интерфейс для сенсорного экрана;
- разделы: Биография, Наследие, Память, Современники, Экскурсия;
- карточки с изображениями, текстами и музыкой;
- встроенный аудиоплеер;
- полноэкранный режим;
- поиск;
- админ-панель с авторизацией;
- добавление, редактирование и удаление материалов;
- загрузка изображений и аудио;
- SQLite;
- работа полностью локально без интернета.

## Запуск
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux:
# source venv/bin/activate

pip install -r requirements.txt
python app.py
```

Открыть: http://127.0.0.1:5000

Админка: http://127.0.0.1:5000/admin/login

По умолчанию:
- логин: `admin`
- пароль: `admin`

Для музея обязательно задайте переменные окружения `ADMIN_USER`, `ADMIN_PASSWORD` и `SECRET_KEY`.

## Сенсорный стол
Chrome:
```bat
chrome.exe --kiosk http://127.0.0.1:5000
```

Материалы хранятся в SQLite, загружаемые файлы — в `static/uploads`.


## Новые музейные режимы

- `/section/chronicle` — интерактивная временная шкала жизни Фёдора Павлова.
- `/music` — отдельный музыкальный зал с крупным сенсорным проигрывателем.
- `/tour` — пошаговая экскурсия.
- `/admin/sections` — управление структурой музея: названия разделов, подписи, порядок, видимость и вложенность.
- У каждого материала может быть основное изображение, текст, аудио и галерея дополнительных фотографий/сканов.
- Через 60 секунд бездействия включается музейная заставка.


## Сборка Windows EXE — ONEDIR

Для музейного компьютера рекомендуется сборка PyInstaller в режиме `--onedir`.

На Windows достаточно запустить:

```bat
build_onedir.bat
```

Скрипт сам:
1. создаст `venv`;
2. установит Flask, Waitress и PyInstaller;
3. удалит старую сборку;
4. соберёт папку `dist\PavlovMuseum`.

Готовый файл:

```text
dist\PavlovMuseum\PavlovMuseum.exe
```

Вся папка `PavlovMuseum` является готовой программой — переносить на музейный компьютер нужно её целиком.

После первого запуска рядом с EXE создаются постоянные данные:

```text
PavlovMuseum\
    PavlovMuseum.exe
    museum.db
    static\
        uploads\
    _internal\
    run_kiosk.bat
```

`museum.db` и `static\uploads` не находятся во временной папке PyInstaller, поэтому тексты, настройки, фотографии и музыка из админки сохраняются между запусками.

Для сенсорного стола можно запускать `run_kiosk.bat`: он стартует сервер и открывает Chrome (или Edge) на `http://127.0.0.1:5000` в полноэкранном kiosk-режиме.

Для ручной пересборки также добавлен `PavlovMuseum.spec`:

```bat
venv\Scripts\activate
pyinstaller PavlovMuseum.spec
```
